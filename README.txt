ALMOST SAID IT — BILINGUAL EDITION V13

ГОТОВЫЙ ФАЙЛ
index.html — версия для публикации на Netlify.
standalone.html — полностью автономная версия: установка, сервер и интернет не требуются.

ПРАВИЛА ИГРЫ
- На ход одной команды вытягивается одна карточка.
- На лицевой стороне ровно четыре вопроса без вариантов и подсказок.
- Каждый вопрос приносит от 1 до 8 баллов в зависимости от сложности.
- На обратной стороне находятся ответы, объяснения и интересные факты.
- На экране передачи телефона нажмите «Начать раунд»: карточка откроется, таймер запустится сразу.
- Кнопка «Показать ответы» переворачивает карточку; жесты для старта не используются.
- Доступно 3, 5 или 7 минут; по умолчанию — 3 минуты.
- Когда время заканчивается, карточка автоматически открывает ответы.
- Ведущий отмечает каждый ответ и передаёт ход следующей команде.

ЧТО ВНУТРИ
- Мобильный интерфейс по выбранному референсу и расширенная версия для компьютера
- Спокойный повторяющийся фон-паттерн в стиле обоев мессенджеров
- Один заметный основной CTA на каждом экране и крупные зоны нажатия
- Анимации на телефоне и компьютере с учётом настройки «уменьшить движение»
- 1000 русских вопросов в семи категориях, из них 171 заново отредактирован
- Отдельная английская редакция: 350 вопросов, по 50 в каждой категории
- Переключатель RU / EN на главном экране и в настройках
- По умолчанию: 2 команды, 3 минуты и игра до 30 баллов
- Настройка 2–6 команд, названий, таймера, цели и категорий
- 3D-переворот карточки, автоматический таймер, подсчёт баллов и финальный рейтинг
- Автоматическое сохранение партии в браузере
- Обновляемая база вопросов

КАК ОБНОВЛЯТЬ БАЗУ
questions.json и questions-en.json — готовые базы для русского и английского языка.
Исходники редакторской базы находятся в russian-editorial.tsv и english-editorial.tsv.
На опубликованном сайте приложение запрашивает этот файл при каждом открытии
и автоматически подключает новые вопросы.

Для автономного standalone.html после изменения базы запустите:
python rebuild-questions.py
node build-standalone.mjs
Пример структуры находится в questions-template.json.

Награда за вопрос задаётся полем points — целым числом от 1 до 8 и уже учитывает
сложность вопроса. При старте каждой новой игры все вопросы выбранных категорий
заново перемешиваются в одну случайную колоду. Карточки берут из неё по четыре
вопроса без повторов, а баллы не сортируются и не идут по возрастанию.

ДЛЯ ДОРАБОТКИ
- index-source.html — разметка и стили
- bold-quiz.css — визуальная система Bold Quiz Club и адаптивность
- app-v7.js — логика игры
- questions.json — редактируемая база вопросов
- questions-ru.js — встроенная копия обеих языковых баз для автономной версии
- i18n.js — перевод интерфейса и динамических подписей
- rebuild-questions.py — собирает обе базы из редакторских TSV и проверяет повторы
- integrate-approved-questions.mjs — полностью заменяет рабочую базу утверждёнными 1000 вопросами
- sync-questions.mjs — проверяет JSON и обновляет questions-ru.js
- build-standalone.mjs — собирает автономный index.html
- SOURCES.md — основные источники и редакционные правила
